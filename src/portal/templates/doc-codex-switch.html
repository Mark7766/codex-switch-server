Codex Switch

让 AI 编程触手可及。一款 macOS / Windows 桌面配置工具，帮你把 Codex、Claude 接到 DeepSeek、智谱 GLM 或自定义供应商——填一次 API Key、点几下按钮即可用，免费开源。

这是什么

Codex Switch 是一款跨平台桌面配置工具。它帮你解决国内使用 Codex、Claude 时的网络与模型问题， 并自动写好 Codex / Claude 的配置文件，让不懂命令行的用户也能几分钟用上：

  • 一键配置：图形界面写好配置，点几下按钮就完成连接；配置生效后应用可以关掉
  • 多种模型：DeepSeek、智谱 GLM、自定义供应商都可接入
  • 直连更安全：各工具直连你选择的供应商，不经过任何中转；Key 存系统钥匙串
  • 免费开源：MIT 协议，Windows 10 · macOS 11+

适合谁

想在国内顺畅用 Codex、Claude，又不想折腾命令行/网络的 AI 开发者与使用者。 无论你用桌面对话窗口还是终端 CLI，都能一条路连上 DeepSeek 等国产可用的模型。

💡 需要 4 款工具里某款未安装？本站 使用指南 提供了对应的下载与安装教程。

解决什么问题

  • 网络受限：官方 Codex / Claude 模型连不上或用得卡 → 改为接入国内可用的模型服务。
  • 配置门槛高：写配置文件、配环境变量太麻烦 → 图形界面一键完成。
  • 模型不好选：贵的用不起、免费的找不到 → 可选 DeepSeek（便宜）、智谱 GLM（中文好）或你自己的兼容 API。
  • 多工具各配各的：Codex、Claude、CLI 每个都要配一遍 → 一处设置全部打通。

填写 API Key

打开 Codex Switch，默认进入「设置」页，在「供应商设置」里填入想用的模型 Key（任选其一）：

  • DeepSeek：到 platform.deepseek.com 注册获取 API Key（便宜、稳定，官方免费申请入口）。
  • 智谱 GLM：到 open.bigmodel.cn 注册获取 API Key（中文能力强、国内网络友好）。
  • 自定义供应商：填入你自己的 Codex Base URL（OpenAI Responses 兼容）与 Claude Base URL（Anthropic 兼容）以及 Key。
🔐 Key 会存入系统钥匙串（macOS Keychain / Windows 凭据管理器），不以明文写在磁盘上。

保存并应用

  1. 在「Codex 接入」卡片里选好供应商与默认模型，点「保存并应用」——它会自动写好 Codex 的配置文件。
  2. 打开 Codex Desktop 或 Codex CLI，直接开始对话：
你好，请用一句话介绍你自己，并告诉我你能帮我做哪 5 件事
  • Claude Desktop：在「Claude Desktop 接入」卡片点一次「保存并应用」，重启 Claude Desktop 后即用。
  • Claude Code CLI（claude）：在「Claude Code CLI 接入」卡片点「保存并应用」，并新开一个终端窗口再运行 claude 才会生效。

验证能用

切到左侧「工具接入状态」，对应的工具显示「已配置」即正常。向 Codex 发一条消息能收到回复就算连上了。 如果发了没反应或报错，先看下方常见问题第一条——多数情况"完全退出 Codex 再打开"即可解决。

支持的 4 款工具

  • Codex Desktop：GUI 对话窗口
  • Codex CLI：终端命令行（macOS 可用 brew install codex）
  • Claude Desktop：GUI 对话窗口
  • Claude Code CLI：终端 claude

每款工具都可以独立选择不同的模型，各配各的、互不干扰。

支持的模型与连接方式

  • DeepSeek（推荐入门）：价格低、速度快。Codex 侧可用 deepseek-flash / deepseek-v4-pro。
  • 智谱 GLM：中文能力强，国内网络友好。可选 glm-5.3 / glm-5.3-flash / glm-5.2。
  • 自定义供应商：填任意兼容 OpenAI Responses / Anthropic Messages 的 Base URL，按需接入。
⚙️ 三家供应商都是直连，不经过任何本地转发。 切换供应商不影响正在进行的对话，也无需重启 Codex。

功能亮点

  • 零命令行：自动写好配置文件，双击安装、点几下就上手，配置生效后应用可以关掉。
  • 一键切换供应商：不重启、不打断对话，各工具各配各的。
  • 直连更安全：各工具直连供应商，不经过任何中转；写入失败会明确报错，改配置前自动备份。
  • 自动更新：默认官方 CDN，可切换 ghproxy 镜像或 GitHub 直连（国内更快），带校验。
  • 配置备份：每次写入前自动备份，历史配置一键回滚。
  • 多模型可读图：新版支持接入视觉模型，直接把截图发给 Codex。

常见问题

Codex 发消息没反应 / 报错？

先确认「设置 → 供应商设置」里该供应商的 API Key 已保存 → 到「Codex 接入」卡片点一次「保存并应用」→ 完全退出 Codex（Mac ⌘Q / Windows 从托盘退出）→ 重新打开再发消息。多数情况是 Codex 缓存了旧配置。

提示 401 / 429 / 额度不足？

401 说明 Key 失效或过期，去控制台重新生成；429 是请求太频繁，等 30–60 秒再试；额度不足则到 DeepSeek 控制台充值。

下载 / 更新很慢？

在 设置 → 自动更新 里把源切到 ghproxy 镜像或 GitHub 直连，下载会快很多；也可直接到本站 下载页 拿最新安装包。

Claude Code CLI 说不认识 claude 或环境没生效？

Codex Switch 把配置写进了你的终端配置文件，需要新开一个终端窗口再运行 claude。

切换供应商后，以前用另一家的对话打不开了？

这是 3.0.0 之前版本的已知问题：切换供应商时会删掉上一家的连接配置，而 Codex 是按对话记住「当初用哪家」的。升级到最新版即可——新版本会保留所有用过的供应商配置。
