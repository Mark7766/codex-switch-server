Codex Switch · 工具 · Codex Switch

Codex Switch

让 AI 编程触手可及。一款 macOS / Windows 桌面工具，在本地帮你把 Codex、Claude 接入 DeepSeek、Agnes AI 等模型——双击安装、点几下按钮即可用，无需翻墙、无需懂命令行，免费开源。

这是什么

Codex Switch 是一款跨平台桌面应用。它帮你解决国内使用 Codex、Claude 时的网络与模型问题， 并自动写好 Codex / Claude 的本地配置，让不懂命令行的用户也能几分钟用上：

  • 一键配置：自动写好本地配置，点几下按钮就完成连接
  • 多种模型：DeepSeek、Agnes AI、智谱 GLM、自定义 API 都可接入
  • 本地安全：代理只在本机 127.0.0.1 上运行，数据不出本机
  • 免费开源：MIT 协议，Windows 11 · macOS 11+

适合谁

想在国内顺畅用 Codex、Claude，又不想折腾命令行/网络的 AI 开发者与使用者。 无论你用桌面对话窗口还是终端 CLI，都能一条路连上 DeepSeek 等国产可用的模型。

💡 需要 4 款工具里某款未安装？本站 使用指南 提供了对应的下载与安装教程。

解决什么问题

  • 网络受限：官方 Codex / Claude 模型连不上或用得卡 → 改为接入国内可用的模型服务。
  • 配置门槛高：写配置文件、配环境变量太麻烦 → 图形界面一键完成。
  • 模型不好选：贵的用不起、免费的找不到 → 内置 DeepSeek（便宜）、Agnes（免费 256K）等。
  • 多工具各配各的：Codex、Claude、CLI 每个都要配一遍 → 一处设置全部打通。

填写 API Key

首次启动会弹出 Setup 向导，让你填入想用的模型 Key（任选其一）：

  • DeepSeek：到 platform.deepseek.com 注册获取 API Key（便宜、稳定，官方免费申请入口）。
  • Agnes AI：到 platform.agnes-ai.com 获取 Key（免费、256K 上下文）。
🔐 Key 会存入系统钥匙串（macOS Keychain / Windows 凭据管理器），不以明文写在磁盘上。

启动并连接

  1. 点「完成并启动代理」，Codex Switch 会自动写好配置，状态变绿即为「运行中」。
  2. 打开 Codex Desktop 或 Codex CLI，直接开始对话：
你好，请用一句话介绍你自己，并告诉我你能帮我做哪 5 件事
  • Claude Desktop：启动时会自动写好配置，打开即用。
  • Claude Code CLI（claude）：配置写入了环境变量，需新开一个终端窗口再运行 claude 才会生效。

验证能用

顶栏状态灯为绿色「代理运行中 ●」即正常。向 Codex 发一条消息能收到回复就算连上了。 如果发了没反应或报错，先看下方常见问题第一条——多数情况"完全退出 Codex 再打开"即可解决。

支持的 4 款工具

  • Codex Desktop：GUI 对话窗口
  • Codex CLI：终端命令行（macOS 可用 brew install codex）
  • Claude Desktop：GUI 对话窗口
  • Claude Code CLI：终端 claude

每款工具都可以独立选择不同的模型，各配各的、互不干扰。

支持的模型与连接方式

  • DeepSeek（推荐入门）：价格低、速度快，直连官方 API，无需本地代理。
  • Agnes AI：免费，256K 上下文，支持工具调用。
  • 智谱 GLM：中文能力强，国内网络友好。
  • 自定义供应商：填任意 OpenAI / Anthropic 兼容的 Base URL，按需接入。
⚙️ Agnes、智谱 GLM 会经本地代理（127.0.0.1:11435）做协议翻译；DeepSeek 与自定义供应商走直连。 切换供应商不影响正在进行的对话，也无需重启 Codex。

功能亮点

  • 零命令行：自动写好配置文件，双击安装、点几下就上手。
  • 一键切换供应商：不重启、不打断对话。
  • 本地安全：代理只监听 127.0.0.1，日志自动打码 API Key，不上传数据。
  • 自动更新：默认官方 CDN，可切换 ghproxy 镜像或 GitHub 直连（国内更快），带校验。
  • 离线插件包：一键装 Codex 插件包（约 36MB、170+ 插件）与 Claude 精选技能。
  • 配置备份：每次写入前自动备份，历史配置一键回滚。
  • 多模型可读图：新版支持接入视觉模型，直接把截图发给 Codex。

常见问题

Codex 发消息没反应 / 报错？

先确认代理绿灯「运行中」→ 设置里点「保存并应用」重写配置 → 完全退出 Codex（Mac ⌘Q / Windows 从托盘退出）→ 重新打开再发消息。多数情况是 Codex 缓存了旧配置。

提示 401 / 429 / 额度不足？

401 说明 Key 失效或过期，去控制台重新生成；429 是请求太频繁，等 30–60 秒再试；额度不足则到 DeepSeek 控制台充值。

下载 / 更新很慢？

在 设置 → 自动更新 里把源切到 ghproxy 镜像或 GitHub 直连，下载会快很多；也可直接到本站 下载页 拿最新安装包。

Claude Code CLI 说不认识 claude 或环境没生效？

Codex Switch 把配置写进了你的终端配置文件，需要新开一个终端窗口再运行 claude。

端口 11435 被占用？

应用会弹窗提示：关闭占用进程后重试，或换一个端口（会自动同步更新配置）。
