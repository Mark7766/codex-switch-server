使用指南

从下载到配置，一步步带你完成

  • 1. 下载安装

  • 3. 启动代理
  • 4. 配置 Codex

  • 6. 常见问题

📥 第一步：下载安装

  1. 前往 下载页面 选择你的操作系统平台。
  2. 下载对应版本的安装包。
  3. macOS：打开 .dmg 文件，将 Codex Switch 拖入 Applications 文件夹。
  4. Windows：运行 .exe 安装向导，按提示完成安装。
  5. 首次启动 Codex Switch 会弹出配置向导，跟随指引完成初始设置。
提示： 如果 macOS 提示"无法验证开发者"，请在系统偏好设置 → 安全性与隐私中点击"仍要打开"。

🔑 第二步：获取 DeepSeek API Key

  1. 访问 platform.deepseek.com 注册账号。
  2. 登录后进入 "API Keys" 页面，点击"创建 API Key"。
  3. 复制生成的 API Key（格式为 sk-xxx）。
  4. 回到 Codex Switch，在配置页面填入 API Key。
提示： DeepSeek 新用户注册即送额度，可以免费试用。API Key 仅保存在你的本机，不会上传到任何服务器。

🚀 第三步：启动代理

  1. 在 Codex Switch 主界面，确认默认模型已选择（推荐 DeepSeek V4 Flash）。
  2. 点击"启动代理"按钮，等待状态变为"运行中"。
  3. 默认代理地址为 http://127.0.0.1:11435，可在设置中修改端口。

💻 第四步：配置 Codex CLI / Desktop

Codex Switch 可以自动配置以下工具的代理设置：

  • Codex CLI — 自动写入 ~/.codex/config.toml 和 auth.json
  • Codex Desktop — 自动配置代理地址和 API Key

在 Codex Switch 设置中找到对应工具的配置项，点击"自动配置"即可。

🧠 第五步：配置 Claude CLI / Desktop

Codex Switch 同样支持 Claude 系列工具的配置：

  • Claude Code CLI — 自动写入 ~/.claude/settings.json 和 shell 环境变量
  • Claude Desktop — 自动配置第三方推理网关配置文件

在设置中开启 "Claude CLI 管理" 或 "Claude Desktop 管理"，Codex Switch 会自动检测已安装的工具并完成配置。

❓ 第六步：常见问题

代理无法启动？

检查端口 11435 是否被其他程序占用。可以在设置中更换端口号。

模型调用报错？

确认 API Key 是否正确填入，确认 DeepSeek 账户是否有余额。可以查看 Codex Switch 的日志定位具体错误。

Claude Desktop 无法连接？

确保 Codex Switch 代理已启动，然后在 Claude Desktop 设置中将 API 地址改为 http://127.0.0.1:11435/anthropic。

下载速度慢？

codex-switch-server 提供了国内镜像，在 Codex Switch 设置中将更新镜像切换为"官方镜像"。
