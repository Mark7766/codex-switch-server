常见问题

代理无法启动？
检查端口 11435 是否被占用，可在设置中更换。
模型调用报错？
检查 API Key 是否正确、DeepSeek 账户是否有余额。
Claude Desktop 安装失败？
确保已启用 Windows 虚拟机平台（VirtualMachinePlatform），在"Windows 功能"中勾选并重启。
PowerShell 命令报错？
确认以管理员身份运行 PowerShell，且已 cd 到 Claude.msix 所在目录。
找不到 Git Bash？
开始菜单搜索 "Git Bash"；或文件夹空白处右键 → "Git Bash Here"；或打开 C:\Program Files\Git\git-bash.exe。
