配置 Codex Switch

  1. 启动 Codex Switch，进入设置
  2. 填入第一步获取的 DeepSeek API Key（sk-xxx）
  3. 选择模型（推荐 DeepSeek V4 Flash）
  4. 点击"启动代理"，等待绿色"运行中"状态

代理地址：http://127.0.0.1:11435

常见问题

代理无法启动？
检查端口 11435 是否被占用，可在设置中更换。
模型调用报错？
检查 API Key 是否正确、DeepSeek 账户是否有余额。
Claude Desktop 安装失败？
确保已启用 Windows 虚拟机平台（VirtualMachinePlatform），在"Windows 功能"中勾选并重启。
PowerShell 命令报错？
确认以管理员身份运行 PowerShell，且已 cd 到 Claude.msix 所在目录。
